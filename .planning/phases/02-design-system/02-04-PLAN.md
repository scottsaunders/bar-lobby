Migrate all hardcoded typography and spacing values in common, controls, and misc components to use design system utilities.

Purpose: This plan covers the design system's own components (common/ and controls/) and miscellaneous components. Some values in control components (especially Button.vue) target PrimeVue internals via `:deep()` and may need `map.get()` instead of utility classes.

  <action>
**For user-facing common components** (Progress.vue, Loader.vue, ContextMenu.vue, Accordion.vue):
Apply the standard migration pattern — add typography/spacing classes to template elements, remove hardcoded values from style blocks.

**For design system control components** (Button.vue, DownloadContentButton.vue, SearchBox.vue, Options.vue, AutoSuggest.vue):
These components use `<style scoped>` with `:deep()` selectors to style PrimeVue internals. Utility classes on the template won't reach inside PrimeVue components. Instead:

1. **Font-size in `:deep()` or component-level selectors:**
   - Replace `font-size: 14px` with `font-size: map.get($text-sizes, "body-2")` if a `$text-sizes` map exists, OR
   - If no SCSS text-size map exists, use the raw pixel value from the typography scale with a comment: `font-size: 14px; /* body-2 equivalent */`
   - For Button.vue specifically: the 5 font-size declarations likely correspond to size variants (slim, default, large). Verify each maps correctly to the typography scale before changing.

2. **Spacing in `:deep()` or component-level selectors:**
   - Replace `padding: 8px` with `padding: map.get($spacing, "sm")`
   - Add `@use "sass:map"` and `@use "@renderer/styles/spacing" as *` imports if not present

3. **If a value targets a PrimeVue internal and can't use tokens** (e.g., PrimeVue sets inline styles that require specific pixel overrides):
   - Keep the hardcoded value with comment: `/* PrimeVue override — must match internal layout expectation */`

**Critical for all files:** Remove the old hardcoded value after applying the token. Don't leave dead properties.
  </action>
