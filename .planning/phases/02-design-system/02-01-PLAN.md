  <action>
For each file, apply this two-step migration:

**Typography (font-size):**
1. Find every `font-size:` declaration in the `<style>` block
2. Map pixel value + font-weight to a typography class using the RESEARCH.md table:
   - 10px/400 → `.caption-2`, 10px/600 → `.caption-2-strong`
   - 12px/400 → `.caption-1`, 12px/600 → `.caption-1-strong`, 12px/700 → `.caption-1-stronger`
   - 14px/400 → `.body-2`, 14px/600 → `.body-2-strong`, 14px/700 → `.body-2-stronger`
   - 16px/400 → `.body-1` (default), 16px/600 → `.subtitle-2`
   - 20px/600 → `.subtitle-1`, 24px/600 → `.title-3`, 28px/600 → `.title-2`
   - For `rem`/`em` values: convert to px first (1rem = 16px)
3. Add the typography class to the corresponding element in the `<template>`
4. Remove `font-size` (and `font-weight` if covered by the typography class) from the `<style>` rule
5. If the CSS rule becomes empty after removal, delete the entire rule

**Spacing (padding/margin/gap):**
1. Find every hardcoded `padding:`, `margin:`, `gap:` with pixel values in `<style>`
2. Map to spacing utilities using the RESEARCH.md table:
   - 2px → `xxs`, 4px → `xs`, 8px → `sm`, 12px → `md`, 16px → `lg`
   - 24px → `xl`, 32px → `xxl`, 48px → `xxxl`, 56px → `xxxxl`
   - Off-scale values: round to nearest token (e.g., 5px → `xs`, 10px → `sm`, 15px → `lg`, 20px → `xl`)
3. For simple values (e.g., `padding: 8px`): add utility class to template element (e.g., `padding-sm`), remove from CSS
4. For directional values (e.g., `padding-left: 16px`): add directional class (e.g., `padding-left-lg`), remove from CSS
5. For compound values (e.g., `padding: 10px 25px`): use `map.get($spacing, ...)` in SCSS instead of utility classes — add the SCSS imports `@use "sass:map"` and `@use "@renderer/styles/spacing" as *` if not already present
6. For `gap`: add `gap-{size}` class to the flex/grid parent element, remove from CSS

**Critical:** Always REMOVE the old CSS property after adding the class. Scoped CSS has higher specificity than global utility classes — leaving both causes the old value to win.

**Edge cases:**
- If a value has no close token match (e.g., 3px, 6px), keep the hardcoded value with a comment: `/* Intentional: off-scale value, no exact token */`
- Dynamic/computed styles (`:style="{ fontSize: ... }"`) are exceptions — leave them
- If the element already has many classes, the utility class still goes on the element, not a wrapper
  </action>
