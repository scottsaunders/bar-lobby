  <action>
For each file, apply the standard migration pattern:

**Typography (font-size):**
1. Find every `font-size:` declaration in the `<style>` block
2. Map pixel value + font-weight to a typography class using the RESEARCH.md mapping table:
   - 10px/400 → `.caption-2`, 12px/400 → `.caption-1`, 14px/400 → `.body-2`
   - 14px/600 → `.body-2-strong`, 16px/400 → `.body-1`, 20px/600 → `.subtitle-1`
   - For `rem` values: convert to px first (0.875rem = 14px → `.body-2`)
3. Add the typography class to the corresponding element in `<template>`
4. Remove `font-size` (and `font-weight` if covered) from `<style>`
5. Delete empty CSS rules

**Spacing (padding/margin/gap):**
1. Find every hardcoded pixel-based spacing in `<style>`
2. Map to utility classes: 4px→xs, 8px→sm, 12px→md, 16px→lg, 24px→xl, 32px→xxl
3. Simple/directional values → utility class on template element
4. Compound values → `map.get($spacing, ...)` in SCSS (add `@use "sass:map"` and `@use "@renderer/styles/spacing" as *` if needed)
5. Off-scale values → round to nearest or keep with comment

**Critical:** Always REMOVE the old CSS property after adding the class. Scoped CSS beats global utilities in specificity.

**File-specific notes:**
- `Messages.vue` has 4 font-size violations — likely message author, content, and timestamp styles
- `MapOverviewCard.vue` has 3 font-size violations — likely map name, size, and player count labels
- `Breadcrumbs.vue` has 1 font-size + 2 spacing — straightforward
