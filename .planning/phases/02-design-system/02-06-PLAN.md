  <action>
For each file, find every `!important` usage and categorize it:

**Category A — PrimeVue override (KEEP with comment):**
If the selector targets a PrimeVue class (`.p-*`, `.pi-*`) or uses `:deep()` to reach into a PrimeVue component, the `!important` is likely necessary because PrimeVue uses inline styles or high-specificity selectors.
→ Add comment: `/* Override PrimeVue default — inline style conflict */` or similar

**Category B — Disabled/state override (KEEP with comment):**
If the `!important` overrides a color variant or state (e.g., `.disabled { opacity: 0.5 !important }` overriding `.green { opacity: 1 }`), it's a legitimate specificity resolution.
→ Add comment: `/* Override color variant specificity for disabled state */`

**Category C — Animation/transition (KEEP with comment):**
If the `!important` is in a transition or keyframe rule (e.g., `height: 0 !important` for list-leave-to), it's necessary for the animation.
→ Add comment: `/* Required for Vue transition animation */`

**Category D — Lazy specificity (FIX):**
If the `!important` could be resolved by increasing selector specificity (e.g., adding a parent selector), fix it:
1. Remove `!important`
2. Increase specificity: `.parent .element` or `.element.modifier`
3. Verify the style still applies correctly

**File-specific notes:**
- `MapOptionsModal.vue` has **31** `!important` usages — these are almost certainly all PrimeVue overrides for the map options modal's dropdown/slider/checkbox components. Batch-comment them.
- `replays.vue` has **11** — likely PrimeVue DataTable or Paginator overrides
- `MapBattlePreviewStartBox.vue` has **11** — likely PrimeVue overrides for start box positioning
- `NavBar.vue` has **7** — mix of PrimeVue overrides and possibly fixable specificity
- `DownloadContentButton.vue` has **7** — evaluate each

**Efficiency tip for large files:** Instead of reading line-by-line, search for `!important` in the file, then read only the surrounding CSS rule to understand context. For `MapOptionsModal.vue`, most rules will be `.p-*` selectors — batch-add PrimeVue override comments.
