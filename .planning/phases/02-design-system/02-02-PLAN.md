  <action>
For each file, apply the standard migration pattern:

**Typography (font-size):**
1. Find every `font-size:` declaration in the `<style>` block
2. Map pixel value + font-weight to a typography class using the RESEARCH.md mapping table
3. Add the typography class to the corresponding element in `<template>`
4. Remove `font-size` (and `font-weight` if covered) from `<style>`
5. Delete empty CSS rules

**Spacing (padding/margin/gap):**
1. Find every hardcoded pixel-based `padding:`, `margin:`, `gap:` in `<style>`
2. Map to spacing utility using RESEARCH.md table (2px→xxs, 4px→xs, 8px→sm, 12px→md, 16px→lg, 24px→xl, 32px→xxl, 48px→xxxl, 56px→xxxxl)
3. Simple values: add utility class to template, remove from CSS
4. Directional values: add directional class (e.g., `padding-left-lg`), remove from CSS
5. Compound values: use `map.get($spacing, ...)` in SCSS
6. Off-scale values: round to nearest or keep with comment

**Critical:** Always REMOVE the old CSS property after adding the class. Scoped CSS has higher specificity than global utility classes.
  </action>
